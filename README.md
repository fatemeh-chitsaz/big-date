# Big Data / Frequent Pattern Mining Coursework

Coursework and notebook implementations for **big-data analytics and frequent-pattern mining**.

## Implemented / studied algorithms

The repository includes exercises around algorithms such as:

- ECLAT;
- FP-Growth;
- OPUS;
- PCY;
- Toivonen's algorithm;
- frequency-based mining exercises.



## Status

This repository is an academic implementation archive. It demonstrates hands-on work with classical data-mining algorithms rather than a production big-data system.
